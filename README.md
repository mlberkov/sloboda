# altrego

Полоса «Система»: корпус сценариев процесса, ход-линтер артефактов оркестратора, журнал кандидатов правок канона.
Репозиторий и система — altrego; пакеты не выделяются и не именуются (ADR-053 §1.2), структура плоская.
Канон живёт в вольте; отсюда не правится иначе как через реестр.
Порядок работы внутри репозитория — [`CLAUDE.md`](CLAUDE.md): ярусы подписи,
запрет записи в вольт, `pull --ff-only` перед прогоном, пороги под корпус
не подгоняются.
