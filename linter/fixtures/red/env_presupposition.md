# RED · env_presupposition

Провенанс: `00-system/canon-corrections-register.md` §B, строка «Исполнимость
shell-блока», вопрос 2 (предпосылки о среде измеряются), К2/К3 — рецидив
2026-08-31, счёт 3. По лестнице лечения §B третий рецидив закрывает дописывание
текста: правило снимается или заменяется механикой, не зависящей от памяти
оркестратора. Этот чекер и есть такая механика, а блок ниже — предмет, на
котором она обязана краснеть.

```bash
pip install --user pyyaml
gcloud run services update theygrow-web --region europe-west1 --min-instances 1
adb -s R58M12ABCDE shell input keyevent 82
```

Каждая из трёх строк адресуется к состоянию среды по имени, взятому не из
измерения этого хода: установка вне venv в среде PEP 668, имя сервиса Cloud Run
и серийник устройства. Провал такого блока неотличим от отсутствия предмета —
владелец видит отказ инструмента, а не ответ про предмет.
