## Ваши действия

1. Прочитать вердикт диспатча на нужном коммите и прислать вывод целиком:

```bash
SHA="$(git rev-parse HEAD)"
gh run list --workflow CI --event workflow_dispatch --commit "$SHA" --json databaseId,conclusion,event
```

Ожидаемо: одна строка с `workflow_dispatch` в поле `event` — фактический вывод на предмете, измерено оркестратором 2026-08-31.

**Конец хода:** нужно слово владельца — назвать вердикт и событие прогона, который он видит.
