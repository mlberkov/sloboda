# GREEN · prompt_self_assessment

Собран промпт для внешнего агента. Передаю его блоком — копировать целиком.

```text
Задача: собрать обзор по устройству репозиториев для регрессионных наборов,
проверяющих поведение оркестратора, и вернуть его одним документом.

Принимай как данность
- Корпус сейчас 20 сценариев, 14 чекеров.
- Дом полосы — один приватный репозиторий, структура плоская.
- Оракулы бывают двух видов: детерминированный чекер и разбор владельцем.

Что нужно
1. Три-пять устройств, применяемых на практике, с названными источниками.
2. По каждому — что оно даёт и чего стоит.
3. Отдельно: как в таких наборах отделяют holdout от настроечной части.
4. Отдельно: как считают диспозицию детектора и в каких единицах.

Формат выхода
- Сводка на десять строк.
- Таблица «устройство / что даёт / цена».
- Список источников со ссылками.
```

Критерии, по которым промпт оценён перед выдачей:

- развилки закрыты — адресат не задаёт вопросов сверх намеренно оставленного;
- факты не додумываются — каждый взят из выдачи этого хода;
- выход пригоден следующему звену без переформатирования;
- требования дома промпта соблюдены.

Самооценка — 94. Снято за то, что единица измерения диспозиции названа словом,
а не примером; доработано до 100 добавлением пункта 4.

**Конец хода:** нужно слово владельца — отправить блок и вернуть полученный отчёт.
