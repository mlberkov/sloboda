# GREEN · smoke_line

Тот же предмет, собранный по проверке пункта: у каждого детектора, выданного
владельцу, есть либо фактический вывод, либо пометка с названным ожиданием.

## Случай 1 — исполнена на предмете

**Строка смоука** для owner-проверки публичной политики:

```bash
test -s public/policy.html || printf 'ВХОД ПУСТ: public/policy.html\n'
grep -c "Версия 1.3" public/policy.html
```

Фактический вывод на предмете (прогон оркестратора 2026-08-31): `1`.

## Случай 2 — не исполнялась, ожидание названо

**Строка смоука** для owner-окружения: не исполнялась — первый прогон у владельца.
Ожидание: команда печатает ровно одну строку вида `revision: theygrow-web-00042-abc`.

**Конец хода:** нужно слово владельца — подтвердить, что вывод у него совпал с процитированным выше.
