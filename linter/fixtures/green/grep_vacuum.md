# GREEN · grep_vacuum

Строка смоука с анти-вакуумной ногой: вход измерен, отрицание произносится явно.

```bash
test -s public/policy.html || printf 'ВХОД ПУСТ: public/policy.html\n'
grep -c "Версия 1.3" public/policy.html
grep -n "нативный экран" src/screens.tsx || printf 'НЕТ СОВПАДЕНИЙ: нативный экран\n'
```

Фактический вывод на предмете (прогон оркестратора 2026-08-31): `1`, затем
`НЕТ СОВПАДЕНИЙ: нативный экран`.

**Конец хода:** нужно слово владельца — подтвердить, что счёт попаданий совпал с тем, что он видит на живой странице.
