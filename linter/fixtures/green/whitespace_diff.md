# GREEN · whitespace_diff

Тот же предмет: счётчик идёт вместе с диффом под фильтром пробелов, и вывод о
содержании строится по второму, а не по первому.

## Ваши действия

1. Сверить правку и прислать вывод целиком:

```bash
git diff --stat HEAD~1 -- public/policy.html
git diff -w --ignore-cr-at-eol HEAD~1 -- public/policy.html
```

Ожидаемо: счётчик и непустой дифф под фильтром — фактический вывод на предмете, измерено оркестратором 2026-08-31.

2. Второй блок счётчиков не несёт вывода о содержании — он только о факте различия:

```bash
git diff --shortstat HEAD~1 -- public/
```

Ожидание: одна строка; вывода о содержании по ней не делается — не исполнялась, первый прогон у владельца.

**Конец хода:** нужно слово владельца — назвать, совпал ли дифф под фильтром с его чтением файла.
