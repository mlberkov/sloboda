# GREEN · sources_trailer

Провенанс формы: та же правка §D, 2026-08-31. Здесь два случая, на которых
чекер по инварианту кричать не должен: packet-handoff с заполненным трейлером,
где у каждого якоря есть строка «что ограничивает», и DR-промпт, называющий
ADR, но задачи плана или реализации для репозитория не несущий, — «Допустимое
попадание» пункта, а не находка.

## Случай 1 — packet-handoff с заполненным трейлером

```text
Задача: собрать implementation plan пакета «долг» по репозиторию altrego,
ветка chore/stage-b-p2-debt.

Контекст
- Долг реестра: триггер по форме против триггера по инварианту.
- Несущий документ, слой 0, пункт 5: отказ контролёра есть отказ хода.
- owner decision 2=а: гейт CI обязателен для слияния.

Sources (якоря вольта, которые кодирует этот handoff)
- ADR-053 §1.2 — плоская структура: ограничивает, что пакеты не выделяются.
- ADR-053 §1.4 — ярусы подписи: ограничивает, что правится без владельца.
- 00-system/canon-corrections-register.md — лестница лечения по счётчику.
- ADR-054 — слой 0 контроля: ограничивает форму отказа механики прогона.

Формат выхода: план реализации, шаги по порядку, план валидации.
```

Критерии оценки обоих промптов: развилки закрыты; факты не додумываются; выход
пригоден следующему звену; требования дома промпта соблюдены. Самооценка — 93.
