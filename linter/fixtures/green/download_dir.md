Тот же предмет: каждая выгрузка несёт явный каталог назначения вне дерева.

## Ваши действия

1. Выгрузить артефакты во временный каталог и прислать перечень файлов:

```bash
gh run download 18422331 --repo theygrow/app --event workflow_dispatch --commit HEAD -D /tmp/dr-18422331
gh release download v0.1.221 --repo theygrow/app --dir "$TMPDIR/rel-0-1-221"
```

Ожидаемо: два каталога вне репозитория — фактический вывод на предмете, измерено оркестратором 2026-08-31.

**Конец хода:** нужно слово владельца — прислать перечень выгруженного.
